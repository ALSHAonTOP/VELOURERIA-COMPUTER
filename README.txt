VELOURERIA — WEBSITE BLOG KULIAH
=================================

Isi folder:
- index.html                  Welcome page / halaman utama
- history-of-computer.html    Sub-blog materi History of Computers
- assets/author-profile.jpeg    Foto profil penulis

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Pastikan index.html, history-of-computer.html, dan folder assets ada dalam satu folder.
3. Klik dua kali index.html untuk melihat homepage di browser.
4. Klik kartu "The History of Computers" untuk membuka sub-blog.

CARA DEPLOY KE VERCEL:
1. Buka https://vercel.com dan login.
2. Buat folder proyek GitHub baru atau unggah proyek melalui metode deploy yang tersedia di dashboard.
3. Jika memakai GitHub: buat repository baru, upload SEMUA isi folder ini, lalu impor repository di Vercel.
4. Framework Preset pilih "Other"; Build Command dan Output Directory bisa dikosongkan untuk situs HTML statis (atau output directory `.` jika diminta).
5. Klik Deploy.
6. Pastikan dua file HTML dan folder assets ikut terunggah. Jangan hanya upload index.html.
7. Jika ingin memakai domain veloureria.space, tambahkan domain melalui Project Settings > Domains dan ikuti instruksi DNS yang ditampilkan Vercel.

CATATAN:
- Foto penulis diletakkan di assets/author-profile.jpeg. Jika foto tidak muncul, pastikan nama file dan folder sama persis.
- Foto ilustrasi komputer menggunakan URL Unsplash dan memerlukan internet.
- Kuis mengambil 5 pertanyaan secara acak dari bank soal, dan pilihan jawaban juga diacak setiap ronde.
- Materi generasi komputer diringkas untuk tugas; cek kembali referensi dan arahan dosen sebelum mengumpulkan.


MATERI DIPERLUAS:
- Konteks sejarah sebelum komputer elektronik modern
- Penjelasan input, processing, storage, output dan siklus instruksi
- Tabel perubahan lintas generasi dan glosarium istilah
- Quiz menampilkan animasi fireworks ketika ronde selesai
