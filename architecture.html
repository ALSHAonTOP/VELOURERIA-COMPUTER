01 · The fundamentals

Apa itu arsitektur komputer?

Arsitektur komputer menjelaskan rancangan dan karakteristik sistem yang berkaitan dengan cara program berinteraksi dengan komputer. Organisasi komputer membahas bagaimana komponen hardware disusun dan bekerja untuk mewujudkan rancangan tersebut.

🧠

CPU — The Processor

Central Processing Unit menjalankan instruksi dan mengendalikan operasi sistem. CPU memiliki unit kendali, ALU, register, serta cache.

💾

Memory & Storage

Register dan cache menyediakan akses sangat cepat. RAM menampung data sementara, sedangkan SSD dan HDD menyimpan data jangka panjang.

↔️

System Bus

Jalur komunikasi menghubungkan komponen. Data bus membawa data, address bus menunjukkan lokasi, dan control signals mengatur operasi.

04 · Inside the CPU

The instruction cycle.

Secara sederhana, satu siklus instruksi terdiri dari fetch, decode, execute, dan pada banyak instruksi, write back.

STEP 01

Fetch

Instruksi berikutnya diambil dari memori menggunakan alamat program counter.

STEP 02

Decode

Control Unit menerjemahkan instruksi untuk menentukan operasi yang diperlukan.

STEP 03

Execute

CPU menjalankan operasi, seperti perhitungan ALU atau pemindahan data.

Write back — simpan hasil

Jika instruksi menghasilkan nilai, hasil dapat ditulis kembali ke register atau memori. Detailnya bergantung pada desain prosesor.

07 · Key takeaways

What to remember.

  • Arsitektur komputer berkaitan dengan rancangan dan karakteristik sistem komputer.
  • Organisasi komputer menjelaskan implementasi dan kerja komponen hardware.
  • CPU menjalankan instruksi; ALU menangani operasi aritmetika dan logika.
  • Register, cache, RAM, dan penyimpanan memiliki fungsi berbeda.
  • Input, pemrosesan, memori, penyimpanan, dan output membentuk satu sistem.

Referensi belajar: William Stallings, Computer Organization and Architecture; David A. Patterson dan John L. Hennessy, Computer Organization and Design.
