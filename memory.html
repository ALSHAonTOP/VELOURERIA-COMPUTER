01

Apa Itu Memory?

Pengertian dan peran memory dalam sistem komputer.

Memory komputer adalah komponen atau media yang digunakan untuk menyimpan data, instruksi, dan hasil pemrosesan agar dapat digunakan oleh komputer. Memory memungkinkan prosesor mengambil informasi yang dibutuhkan ketika menjalankan suatu program.

Ketika sebuah aplikasi dibuka, data dan instruksi yang sedang diperlukan akan ditempatkan pada memory yang sesuai. Prosesor kemudian membaca atau menulis data tersebut. Karena itu, memory berpengaruh terhadap kecepatan kerja, kapasitas penyimpanan sementara, dan kemampuan komputer menjalankan banyak tugas.

Bayangkan seperti meja belajar: penyimpanan (SSD/HDD) adalah lemari untuk menyimpan banyak buku dalam jangka panjang, sedangkan RAM adalah meja tempat buku yang sedang dipakai diletakkan agar mudah dijangkau. CPU berperan seperti orang yang sedang belajar dan mengolah informasi.
Fungsi 01

Menyimpan instruksi

Menampung instruksi program yang akan atau sedang dijalankan oleh prosesor.

Fungsi 02

Menyimpan data

Menampung data masukan, data sementara, dan hasil pengolahan.

Fungsi 03

Mempercepat akses

Menyediakan data sesuai kebutuhan sistem, terutama melalui cache dan RAM.

Fungsi 04

Menjaga informasi

Memory non-volatile dapat menyimpan data meskipun daya komputer dimatikan.

02

Macam-Macam Memory

Memory dapat dikelompokkan berdasarkan fungsi, letak, dan kemampuannya mempertahankan data.

Secara umum, memory komputer dibedakan menjadi memory internal/primer dan memory eksternal/sekunder. Selain itu, ada pembagian berdasarkan sifat penyimpanan, yaitu volatile dan non-volatile.

Memory Primer

Register

Memory berukuran sangat kecil dan sangat cepat yang berada di dalam prosesor. Register menyimpan data, alamat, atau instruksi yang sedang diproses.

Memory Primer

Cache Memory

Memory berkecepatan tinggi yang menyimpan salinan data/instruksi yang sering digunakan CPU. Cache membantu mengurangi waktu menunggu akses ke RAM.

Memory Primer

RAM (Random Access Memory)

Memory utama yang dapat dibaca dan ditulis. RAM menyimpan program dan data yang sedang digunakan. Umumnya bersifat volatile, sehingga isinya hilang ketika daya terputus.

Memory Primer

ROM (Read Only Memory)

Memory non-volatile yang menyimpan firmware atau instruksi penting untuk proses awal perangkat. Isinya tetap tersimpan tanpa aliran listrik.

Memory Sekunder

HDD (Hard Disk Drive)

Media penyimpanan non-volatile yang menggunakan piringan magnetik berputar. Kapasitasnya besar dan cocok untuk menyimpan file dalam jangka panjang.

Memory Sekunder

SSD (Solid State Drive)

Media penyimpanan non-volatile berbasis flash memory tanpa komponen mekanis bergerak. Umumnya memiliki waktu akses lebih cepat daripada HDD.

03

Evolusi Memory dari Generasi ke Generasi

Perkembangan teknologi memory bergerak menuju kapasitas lebih besar, akses lebih cepat, ukuran lebih ringkas, dan konsumsi daya lebih efisien.

Memory berkembang seiring meningkatnya kebutuhan komputer. Teknologi awal memiliki kapasitas dan kecepatan terbatas, kemudian digantikan oleh teknologi semikonduktor yang lebih praktis dan efisien.

1940-an – 1950-an

Memory tabung vakum, delay line, dan magnetic core

Komputer generasi awal menggunakan berbagai teknologi penyimpanan, seperti tabung vakum untuk rangkaian elektronik, mercury delay line pada beberapa sistem, serta magnetic core memory. Magnetic core menyimpan bit menggunakan inti magnet kecil.

1960-an – 1970-an

Semiconductor memory mulai berkembang

Memory berbasis semikonduktor mulai menggantikan teknologi yang lebih besar dan kurang praktis. SRAM dan DRAM berkembang sebagai pilihan memory utama dengan karakteristik biaya, kepadatan, dan kecepatan yang berbeda.

1980-an – 1990-an

DRAM dan modul SIMM berkembang

DRAM menjadi memory utama yang umum pada komputer personal. Teknologi seperti FPM DRAM dan EDO DRAM meningkatkan cara pengambilan data dibandingkan DRAM sebelumnya. Modul memory juga berkembang agar pemasangan lebih praktis.

Akhir 1990-an – 2000-an

SDRAM dan DDR SDRAM

SDRAM menyelaraskan operasi memory dengan clock sistem. DDR SDRAM kemudian mentransfer data pada dua sisi sinyal clock sehingga bandwidth meningkat dibandingkan SDRAM generasi awal.

2000-an – 2010-an

DDR2, DDR3, dan DDR4

Generasi DDR terus meningkatkan transfer data, efisiensi daya, dan kapasitas modul. Setiap generasi memiliki spesifikasi dan bentuk konektor yang perlu disesuaikan dengan motherboard.

2020-an hingga sekarang

DDR5 dan memory berbandwidth tinggi

DDR5 meningkatkan bandwidth dan kapasitas per modul serta membawa perubahan pada pengelolaan daya dan struktur kanal. Pada perangkat khusus, teknologi seperti HBM juga digunakan untuk menyediakan bandwidth sangat tinggi.

Garis besar evolusi: dari media yang besar dan terbatas menuju chip semikonduktor yang semakin kecil, cepat, padat, dan hemat energi. Tidak semua teknologi lama langsung hilang; beberapa tetap digunakan untuk kebutuhan khusus.
04

Perbedaan EDO RAM, SDRAM, dan DDR SDRAM

Membandingkan cara kerja dan kinerja dari masing-masing teknologi.

EDO RAM, SDRAM, dan DDR SDRAM merupakan teknologi DRAM yang berkembang pada periode berbeda. Perbedaan utamanya terdapat pada cara mengakses data dan hubungan transfer data dengan sinyal clock.

EDO RAMExtended Data Out DRAM mempertahankan keluaran data dari satu siklus agar dapat tetap tersedia ketika akses berikutnya dimulai.Lebih efisien daripada FPM DRAM pada pola akses tertentu karena mengurangi jeda antarakses.Belum tersinkronisasi dengan clock sistem seperti SDRAM dan bandwidth-nya terbatas menurut standar modern.
SDRAMSynchronous DRAM bekerja selaras dengan clock sistem sehingga operasi pembacaan dan penulisan dapat diatur mengikuti siklus clock.Timing lebih teratur dan mendukung operasi burst; kinerjanya lebih baik dibanding DRAM asinkron generasi sebelumnya.Transfer data pada SDR SDRAM dilakukan satu kali per siklus clock, sehingga bandwidth lebih rendah dibanding DDR pada clock yang sama.
DDR SDRAMDouble Data Rate SDRAM mentransfer data pada rising edge dan falling edge sinyal clock.Dapat melakukan dua transfer data per siklus clock, sehingga secara teori menggandakan laju transfer dibanding SDR SDRAM pada clock yang sama.Memerlukan dukungan motherboard dan prosesor yang sesuai; generasi DDR berbeda tidak saling kompatibel secara fisik maupun elektris.

EDO RAM — Extended Data Out

EDO RAM memperpanjang ketersediaan data pada jalur keluaran sehingga siklus akses berikutnya dapat dimulai lebih awal. Teknik ini membantu mengurangi waktu tunggu dibanding FPM DRAM pada kondisi tertentu.

Mini Glossary

Istilah penting yang sering muncul dalam pembahasan memory.

Volatile

Sifat memory yang membutuhkan daya listrik untuk mempertahankan data.

Non-volatile

Sifat media penyimpanan yang tetap menyimpan data walaupun daya dimatikan.

Bandwidth

Jumlah data yang dapat ditransfer dalam suatu rentang waktu.

Latency

Waktu jeda antara permintaan akses data dan saat data mulai tersedia.

Clock

Sinyal periodik yang membantu menyelaraskan operasi komponen digital.

DRAM

Dynamic RAM yang menyimpan bit dalam kapasitor dan perlu di-refresh secara berkala.
